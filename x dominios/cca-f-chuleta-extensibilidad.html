Eje 2 · Cuánta autoridad

Una instrucción es probabilística: Claude la sigue casi siempre, pero puede fallar en sesiones largas, en situaciones ambiguas o por una prompt injection en un fichero que abre durante la tarea. Una barrera real tiene que ser determinista, y lo determinista son hooks y permisos. Un hook PreToolUse puede inspeccionar cualquier llamada a herramienta y salir con código 2 para denegarla.

Por encima de todo están los managed settings: los despliega un administrador, el usuario no puede sobrescribirlos con su configuración local y son la única forma de imponer una barrera determinista a nivel de organización.

Ojo con output styles: sustituyen al estilo por defecto salvo que pongas keep-coding-instructions: true, y con ello se van instrucciones críticas de Claude Code (cómo acotar cambios, cuándo comentar código, qué hacer con temas de seguridad, verificar antes de dar algo por terminado).

MCP en detalle

Estándar abierto para conectar a Claude con datos y herramientas externas. Por debajo es JSON-RPC 2.0 sobre dos transportes: stdio (servidor local como proceso hijo) o HTTP para remotos, con OAuth nativo. SSE está deprecado en favor de streamable HTTP.

Las tres primitivas

Tools

Acciones que Claude ejecuta: llamar APIs, correr comandos, modificar datos.

Resources

Datos que Claude lee: esquemas de BD, árboles de ficheros, respuestas de API. Se cargan al referenciarse.

Prompts

Plantillas reutilizables. En Claude Code aparecen como slash commands: /mcp__servidor__prompt.

Los tres scopes

ScopeDónde viveQuién lo veCuándo usarlo
local por defecto~/.claude.jsonSolo tú, solo en ese proyectoPruebas y servidores personales de un proyecto
project.mcp.json en la raízTodo el equipo, se commitea a gitInfraestructura compartida
user~/.claude.jsonSolo tú, en todos tus proyectosUtilidades que quieres en todas partes

Se añaden con claude mcp add y --scope project o --scope user. Dentro de sesión, /mcp muestra estado de conexión, tools disponibles y prompts de autenticación. La primera vez que Claude Code ve un servidor de scope project te pide aprobarlo: ese permiso existe para que un repo que clonas no pueda lanzar procesos en tu máquina sin tu consentimiento.

Los dos puntos de arquitectura

Coste. Cada servidor conectado ocupa sitio en la ventana, porque sus nombres de tools e instrucciones se cargan en cada sesión, se usen o no. De ahí que convenga desconectar los que no uses, y que una herramienta con equivalente en CLI (gh, aws) salga más barata en contexto: no añade definiciones persistentes.

Riesgo. Cuidado con servidores MCP que traen contenido no confiable: pueden exponerte a prompt injection. Es una restricción de diseño, no una nota al pie.

Repaso rápido

Hook o skill

Garantía frente a criterio. El hook se dispara siempre y no piensa; la skill son instrucciones que Claude interpreta. Formatear al guardar es un hook; un checklist de release es una skill.

Skill o subagent

Skill si quieres ver y dirigir cada paso dentro del hilo principal. Subagent si los resultados intermedios ensuciarían la conversación y solo te importa el resultado final.

MCP o skill

Conexión frente a know-how. MCP te da la herramienta; la skill enseña a usarla bien.

Rule o CLAUDE.md de subdirectorio

Rule con paths cuando la restricción es transversal y afecta a ficheros repartidos por varios rincones del repo. CLAUDE.md de subdirectorio cuando la convención pertenece a esa carpeta concreta.

Output style o append-system-prompt

El output style sustituye el prompt por defecto y cambia el rol; el flag solo añade y se aplica a esa invocación. Si solo quieres tocar tono o formato, el flag es menos destructivo.

Cuántos niveles anidan los subagents

Hasta cinco. Y los dynamic workflows orquestan de decenas a cientos de agentes en segundo plano, con el plan y los resultados intermedios en variables de script en vez de en la ventana de contexto.

CLAUDE.md es conocimiento siempre activo. Rules son restricciones. Skills es conocimiento bajo demanda. MCP son conexiones. Subagents son aislamiento. Hooks son garantías. Plugins son el zip de todo lo anterior.

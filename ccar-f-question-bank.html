Session termination safeguards

Every session ends in one of exactly two states: a completed resolution, or a handoff to a human. A loop that ends any other way — token limit, iteration cap, unhandled error — routes to escalation rather than falling silent.

Structured handoff packages

Carry accumulated context, findings, and authorization state. The receiver should never need to redo work or re-derive what the agent was permitted to do.

Dynamic subtask decomposition

Subtasks are generated as findings arrive, not fixed up front. A plan that executes the same sequence regardless of what step two discovered is the anti-pattern.

PreToolUse hooks

Run before the call and can block it. This is where business rules and policy constraints live when they must not be left to model discretion.

PostToolUse hooks

Run after the call completes. Cannot prevent the edit, but enforce what comes next — formatting, linting, tests — on every edit, independent of instruction-following.

Permissions vs. CLAUDE.md

Anything that must hold regardless of the model's judgment is a settings permission or a hook. CLAUDE.md is guidance the model weighs, which is the right home for conventions and the wrong home for boundaries.

Choosing the configuration mechanism

CLAUDE.md for always-on project context. .claude/rules/ with globs for guidance scoped to matching files. Skills for procedures loaded on demand. Hooks and permissions for anything deterministic.

Custom slash commands

Markdown files whose filename becomes the command. .claude/commands/ in the repo for team-shared commands; ~/.claude/commands/ for personal ones across all your projects. Frontmatter carries the description, argument hint and allowed tools.

MCP server scope

Project scope for shared team tooling, user scope for personal or experimental servers.

Providing project context

@ references for a specific file needed right now. CLAUDE.md for context that is reusable across sessions. Inline description for a one-off detail that will not recur.

Sync vs. batch processing

Messages API when something is blocked waiting on the result. Message Batches API for large asynchronous volumes: half the token cost, a processing window of up to 24 hours, and no streaming.

Structured output method

Strictest compliance comes from tool use with a JSON schema. Prefilled responses shape the start of a format. Prompt-based formatting is the loosest and the wrong answer when a parser depends on it.

Extraction schema design

Optional fields, nullable values and enums exist so the model can represent missing or ambiguous information instead of inventing it.

Tool use to enforce structured output

Define the schema, and force invocation with tool_choice when a conversational reply would break something downstream.

Feedback loops

Capture structured metadata about model errors — what field, what document type, what the correction was — and feed the pattern back into prompts, schemas and few-shot examples.
